📱 How to connect it

1. Create a Firebase project and register a Web app.

2. Create Realtime Database and enable Anonymous Authentication.

3. Copy your Firebase web configuration into the marked section in this file.

4. Put this HTML on an HTTPS web host. Your friends open the same website and use the room code.

The database is realtime, so changes made by one player are pushed to the other players automatically.
