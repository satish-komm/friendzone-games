📱 How it works

1. One player creates a room.

2. Share the 6-digit room code.

3. Friends join the same room.

4. Host chooses a game.

5. Press Start Game.

6. Everyone plays together in realtime.

FriendZone uses Firebase Authentication and Realtime Database for multiplayer synchronization.
